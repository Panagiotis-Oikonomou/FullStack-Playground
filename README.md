# Web Development Playground

A personal collection of small web development projects built with React and Node.js.

## About

This repository is part of my personal journey to practice, improve, and strengthen my web development skills before starting my mandatory military service.

Over the next six months, I plan to build small projects, experiment with different technologies, and apply concepts I learned during my university studies and thesis.

The goal is to learn by building, explore new ideas, and gradually develop more complex applications.
